what i played
this week

this one is intentionally less serious. future blog entries should be allowed to contain thoughts with absolutely no professional value whatsoever.

i played a little game with rooms that felt less like rooms and more like punctuation marks. every object suggested a rule without explaining it. i enjoyed being left alone with the problem.

the best part was probably getting lost, which is inconvenient in software and excellent in games.

good game design sometimes feels like someone removed all the tutorial text five minutes before release and accidentally improved everything.

this is also the place where i could later write about a mechanic, put a screenshot between paragraphs, add another giant heading, or simply say that i played something for forty minutes and liked the frogs.
