tiny things that make
software feel alive

a demo post about small interface decisions, mostly written so we can see code, text and a compact visual living together.

today's completely arbitrary observation: a tiny confirmation can make an interface feel much more trustworthy than a giant success modal. the software says “done” and then gets out of the way.

if (task.isValid()) {
    task.save();
    ui.confirmQuietly();
}

there is probably a whole philosophy hiding inside boring defaults. the best interaction is often the one you barely notice because nothing interrupts the thing you were actually trying to do.
