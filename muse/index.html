how to use this app

Objects

  • T Table · L List · B Bang · D Moscow time · A Alarm · C Calendar. Двойной щелчок по холсту создаёт заметку.
  • У таблиц независимые размеры колонок и строк; размер меняется перетаскиванием границ. Заголовки заметок редактируются в Inspector.
  • List начинает с девяти задач; после заполнения последней появляется следующая пустая строка. Отмеченные задачи зачёркиваются.
  • I открывает Inspector выбранного объекта. Для календаря настройки пока не предусмотрены.

Connections

  • Соединяйте output одного объекта с input другого с помощью patchcord. Каждая колонка таблицы имеет собственную пару портов.
  • Alarm окрашивает связанные объекты красным в заданное время; удаление связи возвращает их обычный вид.

Canvas

  • ⌘/Ctrl+A выделяет группу. Esc снимает выделение. Backspace/Delete удаляет выбранное.
  • Перетаскивание пустого поля двигает холст; ⌘/Ctrl + колесо меняет масштаб. Изменения сохраняются автоматически; «↓ файл» создаёт JSON-копию.
